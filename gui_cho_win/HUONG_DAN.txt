==========================================================
  CÔNG CỤ CHICHBONG IMAGEN4 — chạy trên Windows
==========================================================

Gói này TỰ ĐỦ — copy cả thư mục sang Windows là chạy được.

----------------------------------------------------------
ĐIỀU KIỆN CHUNG:
  1. Cài Python (python.org) — TICK "Add Python to PATH".
  2. Đã cài + ĐÃ KÍCH HOẠT app ChichBong trên máy này
     (để tool tự đọc license từ máy).
----------------------------------------------------------

CÓ 2 CÔNG CỤ (double-click file .bat tương ứng):

▶ 1) TẠO ẢNH LẺ 2K / 1K:
     MO_GIAO_DIEN_2K.bat
     → Gõ mô tả, chọn 1K/2K + tỉ lệ, bấm tạo. Ảnh vào thư mục anh_2k.

▶ 2) CHẠY NHIỀU SHEET (Sheet → Ảnh → Drive → ghi link):
     MO_GIAO_DIEN_SHEET.bat
     Các bước trên giao diện:
       1. Chọn file credentials (.json)  — chìa khóa Google.
       2. Bấm "Đăng nhập Google"          — mở trình duyệt xác thực.
       3. Chọn file danh sách sheet (.txt) — mỗi dòng 1 link sheet.
       4. Folder Drive lưu ảnh (mặc định root = My Drive).
       5. Bấm "BẮT ĐẦU CHẠY".

Lần đầu chạy hơi lâu (tự cài thư viện). Từ lần 2 nhanh.

----------------------------------------------------------
LƯU Ý:
 - File .json credentials và file .txt link sheet: bạn tự chuẩn bị
   rồi chọn trên giao diện (có thể để cạnh thư mục này cho tiện).
 - Nếu báo "Không thấy license": chưa kích hoạt app ChichBong.

CHẨN ĐOÁN (khi cần): kiem_tra_win_chichbong.bat
