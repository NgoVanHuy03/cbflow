==========================================================
  TẠO ẢNH 2K — ChichBong Imagen4 (gói chạy trên Windows)
==========================================================

Gói này TỰ ĐỦ — chỉ cần copy cả thư mục này sang máy Windows.

----------------------------------------------------------
ĐIỀU KIỆN:
  1. Đã cài Python (python.org) — TICK "Add Python to PATH".
  2. Đã cài + ĐÃ KÍCH HOẠT app ChichBong trên máy này
     (để máy có license trong Registry → tool tự đọc).
----------------------------------------------------------

CÁCH CHẠY (chọn 1):

  ▶ CÓ GIAO DIỆN (khuyên dùng):
      Double-click:  MO_GIAO_DIEN_2K.bat
      → Mở cửa sổ: gõ mô tả ảnh, bấm "TẠO ẢNH 2K".

  ▶ DÒNG LỆNH (đơn giản):
      Double-click:  tao_anh_2k.bat
      → Gõ mô tả, ảnh lưu vào thư mục  anh_2k

Lần đầu chạy hơi lâu (tự cài thư viện). Từ lần 2 nhanh.
Ảnh tạo ra lưu trong thư mục  anh_2k  (cùng chỗ).

----------------------------------------------------------
NẾU BÁO "Không tìm thấy license":
  → Chưa cài/kích hoạt app ChichBong trên máy này.
  → Mở app ChichBong, đăng nhập/kích hoạt xong rồi chạy lại.

CHẨN ĐOÁN (nếu cần):
  Double-click  kiem_tra_win_chichbong.bat
  rồi gửi lại file  ket_qua_chichbong.txt
----------------------------------------------------------

Cấu trúc gói (không xoá file nào):
  MO_GIAO_DIEN_2K.bat        ← mở giao diện
  tao_anh_2k.bat             ← chạy dòng lệnh
  tao_anh_2k_gui.py          ← code giao diện
  tao_anh_2k.py              ← code dòng lệnh
  requirements.txt           ← danh sách thư viện
  services\                  ← engine ChichBong
  kiem_tra_win_chichbong.bat ← chẩn đoán (khi cần)
